# Relighting Images with Three.js

A little magic trick using depth maps, TSL, and WebGPU to make flat 2D images react to dynamic lighting like 3D surfaces, with surface detail and self-shadowing.

![Featured Image](https://tympanus.net/codrops/wp-content/uploads/2026/08/mother.png)

[Article on Codrops](https://tympanus.net/codrops/?p=119000)

[Demo](https://tympanus.net/Tutorials/RelightingImages/)

## Installation

```bash
npm install
npm run dev
```
